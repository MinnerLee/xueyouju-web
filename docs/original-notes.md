<a id="continuity"></a>
## §1 连续与可导

函数在 x₀ 处可导，要求差商 [f(x₀+h)−f(x₀)]/h 在 h→0 时存在有限极限。可导必连续：将函数增量写成差商与 h 的乘积，可知增量趋于 0。

反向结论不成立。f(x)=|x| 在 0 处连续，但左导数为 −1，右导数为 1，故不可导。判断分段点是否可导，应先检查函数值和连续性，再检查左右差商。

自编小测：f(x)=x（x≥0），f(x)=2x（x<0）。在 0 处连续，但左右导数分别为 2 和 1，因此不可导。

<a id="limit"></a>
## §2 极限与函数值

函数在 x₀ 处的极限研究去心邻域内 x 趋近 x₀ 时的函数值，不要求 f(x₀) 存在。连续则要求 f(x₀) 有定义、极限存在且等于函数值。

例如 (x²−1)/(x−1) 在 1 处未定义，但在 x≠1 时等于 x+1，其极限为 2。约分仅在分母非零的范围内成立。

自编小测：f(x)=(x²−4)/(x−2)（x≠2），另定义 f(2)=7。x→2 时极限为 4；极限不受孤立点值的改变影响，但该函数在 2 处不连续。

<a id="mean-value"></a>
## §3 拉格朗日中值定理的条件

若 f 在闭区间 [a,b] 连续，并在开区间 (a,b) 可导，其中 a<b，则存在 ξ∈(a,b)，使 f′(ξ)=[f(b)−f(a)]/(b−a)。两项条件都要检查。

f(x)=|x| 在 [−1,1] 上连续，但在内点 0 处不可导，不能应用该定理。两端平均变化率为 0，而有导数的内点处导数仅为 ±1。

自编小测：f(x)=x² 在 [1,3] 上符合定理条件，平均变化率为 4；由 2ξ=4 得 ξ=2。

<a id="loop"></a>
## §4 循环边界

长度为 n 的数组合法元素下标为 0 到 n−1。for 循环在每次进入循环体前判断条件。若 i 从 0 开始、每次加 1，条件 i<4 只允许 i 取 0、1、2、3。

对于长度为 5 的数组，i<5 可以遍历全部元素，i<=5 会多出非法下标 5。对于长度为 8 的数组，完整且不越界的条件为 i<8。

以上为依据循环语义的静态推演，没有运行编译器。

<a id="array"></a>
## §5 数组下标与长度

C 数组采用从 0 开始的下标。第 k 个元素对应 a[k−1]。长度为 6 的数组最后一个元素是 a[5]，不是 a[6]。越界读写的行为未定义，不能预言一个固定输出。

对于 int scores[10]，第 9 个元素是 scores[8]。

<a id="parameter"></a>
## §6 普通参数的值传递

C 函数普通参数采用值传递。形参得到实参值的副本；对形参重新赋值，不会修改调用者的原变量。可以传入地址并通过解引用修改所指对象。

例如 void f(int n){n++;}，若调用前 a=3，f(a) 返回后 a 仍为 3。这是规则推演，非实际执行日志。
