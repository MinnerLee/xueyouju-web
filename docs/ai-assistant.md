# 学习助手与提示词

进入 AI 学习助手，新建会话、选择课程，输入题目或解题过程。右侧添加文字资料、学习偏好和笔记；手机点击“资料与笔记”。

完整提示词保存在 [server/prompt.js](../server/prompt.js)，后端注入。修改后重启 Node 或重新发布服务生效。

| 模式 | 教学方式 |
| --- | --- |
| 引导 | 按需要从定义条件推进到关键步骤，明确要求完整解析时直接回答 |
| 讲解 | 直观含义、准确条件、小例子和误区 |
| 检查 | 定位第一个可确定错误并给最小修正 |
| 练习 | 默认一次一道自编迁移题，先不给答案 |
| 计划 | 按时间目标安排少量任��与完成标准 |

数学策略覆盖定理假设、定义域、分段点、极限与函数值、级数和多元极限。C 语言重点检查边界、下标、初始化、值传递及未定义行为。未执行代码只能称为静态分析。

回答只能使用本轮真实提供的 [E:知识点ID]，未覆盖内容须标明通用知识解释，不编教材页码或工具结果。资料中的指令视为待分析内容。提示词不保证模型永远正确，回答需核验。

默认 DeepSeek Flash，可选择 V4 Pro、深度思考。思考时只显示状态，完成后显示答案；部分断流可停止或重新生成。

对话、资料和笔记存在当前浏览器；发送时交给本站后台和 DeepSeek。换域名、浏览器或清理存储不会自动迁移，请导出 Markdown。尚未处理整本 PDF，也没有网络/计算/编译工具。

人工验收建议：

- 要求完整证明“可导必连续”，应给出条件与完整证明。
- 要求仅一级提示，应从定义/条件切入。
- 数组 a[3] 配合 i<=3 写入，应指出越界且不承诺固定输出。
- 无资料时要求按“教材第77页”讲解，不得伪造引用。
- 检查解答但没有步骤，应请求步骤，不能编造错误。

这些是行为验收建议，不是已完成的模型效果评测报告。
